# 제목 기반 금융 글 파이프라인 컨텍스트 노트

## 2026-07-08

사용자는 새 니치를 찾는 것이 아니라, 제공한 제목 목록을 분석해 글별 작성 가이드와 내부링크 구조를 잡고 싶다고 했다.

1차 범위는 금융 & 재테크 30개 글로 확정했다. 이유는 Blogger 임시저장, URL 맵 생성, 내부링크 치환까지 외부 API가 걸려 있어서 전체 180개를 한 번에 처리하면 실패 복구가 어렵기 때문이다.

기존 `planner.py`는 니치에서 제목을 발굴하는 흐름이므로 이번 작업과 목적이 다르다. 새 파일 `title_planner.py`를 추가해 제공된 제목을 그대로 유지하고, 기존 `generator.py`가 읽을 수 있는 `plan_finance_2026.json`을 만드는 방향으로 설계했다.

1차 내부링크는 `prev`, `next`, `hub`만 사용한다. `related` 같은 고급 링크는 1차 검증 뒤 추가하는 편이 안전하다. 기존 `linker.py`가 이 세 링크를 이미 처리하기 때문이다.

`publisher.py`는 이미 `isDraft=True`로 Blogger 초안 저장을 하므로 공개 발행 방지용 추가 변경은 우선 필요 없다.
