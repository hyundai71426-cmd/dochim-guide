# 네이버 블로그 제목 목록 사이드패널 - 진행 상황

## 프로젝트 개요

네이버 블로그 포스팅 중 "함께보면 좋은 글" 링크를 쉽게 달 수 있도록, 크롬 사이드패널에 블로그 게시글 제목과 링크를 모아 보여주고 클릭 한 번으로 URL을 복사하는 크롬 확장 프로그램.

관련 문서: [설계 문서](docs/superpowers/specs/2026-07-08-naver-blog-sidepanel-design.md), [체크리스트](checklist.md), [컨텍스트 노트](context-notes.md)

## 현재 상태: 기능 구현 완료, 사용자 실사용 테스트로 버그 수정 중

## 아키텍처 (최종)

최초 설계는 "현재 활성 탭의 목록을 실시간으로 사이드패널에 반영"하는 방식(content-script → 메시지 → 사이드패널)이었으나, 실사용 중 발견된 문제들로 **chrome.storage.local에 발견한 글을 계속 누적 저장하는 방식**으로 전환했다.

- `content-script.js`: 네이버 블로그 카테고리 페이지에서 게시글 제목/링크를 추출해 `chrome.storage.local`의 `posts` 객체에 누적 저장 (key: `blogId`+`logNo` 기반 표준 URL)
- `sidepanel.js`: 저장소 전체를 읽어와 렌더링, `chrome.storage.onChanged`로 실시간 반영. 탭이나 화면 상태와 무관하게 항상 저장된 전체 목록을 보여줌
- `background.js`: 액션 아이콘 클릭 시 사이드패널이 열리도록 설정만 담당
- 각 항목: 제목 + 복사 버튼(URL만 클립보드에 복사) + 삭제(✕) 버튼 (개별 삭제만 지원, 전체 삭제는 없음)
- 목록은 `logNo` 기준 내림차순 정렬로 최신 글이 항상 위에 오도록 함

## 해결한 문제들

1. **가상 스크롤로 인한 목록 누락** — 네이버 블로그 목록이 스크롤 위치에 따라 화면에 보이는 것만 DOM에 렌더링되는 방식이라, 스크롤을 내린 상태에서는 일부 글만 읽혔다. → 실시간 반영 방식 자체를 버리고 저장소 누적 방식으로 전환해 근본 해결.
2. **탭 전환/화면 이동 시 목록 사라짐** — 글쓰기 화면처럼 목록이 없는 페이지로 이동하면 패널이 비었다. → 저장소 기반으로 바뀌면서 어떤 화면에 있든 마지막까지 쌓인 전체 목록이 유지됨.
3. **추적 파라미터로 인한 중복 저장** — 같은 글이 캡처된 위치에 따라 `from=` 등 URL 파라미터가 달라 다른 글로 인식되어 중복 표시됐다. → `blogId`+`logNo`만 추린 표준 URL을 키로 사용하도록 수정, 기존 중복도 다음 캡처 시 자동 정리.
4. **확장 프로그램 리로드 시 "Extension context invalidated" 오류** — 개발 중 확장 프로그램을 새로고침해도 이미 열려있던 사이드패널이 낡은 연결 상태로 남아 발생. 코드에서 `chrome.runtime.id` 존재 여부를 사전 체크해 방어하고, 안내 문구로 대체. (근본적으로는 확장 새로고침 후 패널을 완전히 닫았다가 다시 열어야 해결됨 — 일반 사용자는 개발 중 리로드를 하지 않으므로 실사용에서는 발생하지 않음)
