# 카드뉴스 CTR 가이드 (Phase 3 템플릿·프롬프트 설계 기준)

작성일: 2026-07-05. 웹 리서치 기반 정리 — Phase 3 구현 브리프의 설계 근거 문서.

## 1. 표지(1장) — 클릭의 80%가 여기서 결정
독자는 표지를 보고 **2초 안에** 읽을지 결정한다. 표지 문구는 **8단어 이내**.

문구 공식 (우선순위 순, LLM 프롬프트에 반영):
1. **구체적 이득 명시** — 추상 금지. ❌"청년들에게 희망을" → ✅"알바생을 위한 노동법 7가지"
2. **숫자 활용** — "5가지", "3분 만에", "월 10만원" (클릭률 상승 검증된 패턴)
3. **타깃 명시** — "~하는 사람만", "초보 ○○를 위한" (해당 타깃의 클릭·태그·공유 유발)
4. **시의성/상황** — "지금", "이번 주", "2026년 바뀐"
5. **호기심 갭** — 상식을 비트는 문구. 단, 내용이 받쳐줄 때만(낚시 금지)

표지 디자인:
- 타이틀 크고 굵게, 배경은 단순하게(복잡한 배경 금지), 강한 대비
- 줄바꿈은 **두세 단어 단위**로 (한 번에 인식되는 단위)
- 강조 단어(숫자·핵심어)만 포인트 컬러

## 2. 구성 — 표지 1 + 본문 4~8 + 마지막 1 (총 6~10장)
- **본문 카드: 카드 1장 = 메시지 1개.** 여러 내용 욱여넣기 금지
- 카드당 **제목 20자 이내 + 본문 50자 내외** (모바일 가독 한계)
- 카드에 **번호/진행 표시**(예: 2/7) — 끝까지 넘기게 하는 장치
- **마지막 장 = CTA**: 핵심 요약 1줄 + 행동 유도("저장해두고 필요할 때 보세요", "팔로우하고 더 알아보기", 블로그 전문 유도). 인스타에서 **저장 수**가 도달에 가장 중요한 지표

## 3. 디자인 규칙 (고정 템플릿에 반영)
- **색상은 2~3개로 제한**: 배경 1 + 본문 텍스트 1 + 포인트 1. 시리즈 전체 통일
- 폰트는 고딕 계열(Noto Sans KR), 제목/본문 크기 계층 분명하게
- **여백 충분히** — 갑갑하면 안 읽음. 텍스트는 중앙 정렬 기본
- 제목-부제-본문의 시각적 계층화, 그래프·아이콘 등 시각 요소는 절제해서
- 사이즈: **1080×1080 (1:1)** — 인스타 피드/캐러셀 + 스레드 공용 (사용자 결정).
  참고: 인스타 단독이라면 4:5(1080×1350)가 노출 면적이 더 크지만, 스레드 겸용을 위해 1:1 유지

## 4. 우리 파이프라인 적용 방침
- **고정 HTML/CSS 템플릿 + LLM은 텍스트만 채움** (기존 결정 유지 — 디자인 일관성·품질 보장)
- 표지 문구는 블로그 제목 재활용이 아니라 **표지 전용 후킹 문구를 별도 생성** (위 공식 1~5를 프롬프트 규칙으로)
- 본문 카드는 블로그 H2 요약이 아니라 **"카드당 1메시지" 단위로 재추출** (H2 개수와 무관)
- 마지막 카드는 요약+CTA 고정 슬롯 (저장 유도 문구 + 블로그 유도)
- 템플릿 3종(색 테마) 정도로 시작, 작업별로 랜덤/선택
