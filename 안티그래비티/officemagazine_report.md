- 카테고리: `/property-type/{한국어-카테고리}/`

## 5. 사이트 전략 분석

### 5.1 강점
1. **지역 특화**: 강남·서초 지역 사무실 임대에 전문 집중
2. **콘텐츠 양**: 약 400페이지 이상의 풍부한 콘텐츠
3. **법적 정보**: 상가임대차 관련 전문 법률 정보 제공으로 신뢰도 향상
4. **매물 상세도**: 각 매물마다 평수, 보증금, 월세, 주변 역, 주차, 냉난방 등 상세 정보
5. **추천 매물 시스템**: 각 매물 페이지에서 관련 매물 3선을 추천하여 사용자 체류 시간 향상

### 5.2 개선 제안
1. **영어 URL 슬러그**: 블로그 포스트는 영어 슬러그를 사용하지만, 서비스/매물 페이지는 한국어 슬러그 사용 — 일관성 필요
2. **모바일 최적화**: WordPress 기반이므로 반응형 디자인 확인 필요
3. **블로그 콘텐츠 확대**: 법적 정보 중심 → 시장 동향, 분석, 인사이트 등 다각화 가능
4. **내부 링크 강화**: 블로그 ↔ 매물 페이지 간 내부 링크 최적화로 SEO 강화
5. **리뷰/후기 콘텐츠**: 거래 후기, 기업 인터뷰 등 사회적 증거 콘텐츠 추가
